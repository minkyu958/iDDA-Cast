The Exchange Rate dataset is an important benchmark for long sequence time-series forecasting (LSTF) in the financial domain. This dataset contains 7,588 daily observations of exchange rates from January 1990 to October 2010. Each data point consists of 8 exchange-rate variables, reflecting the changes and fluctuations of currency values over time. The dataset can be used to evaluate forecasting models under changing trends, irregular fluctuations, and potentially weak seasonal patterns. The train/validation/test split is 70%/10%/20% in chronological order.
